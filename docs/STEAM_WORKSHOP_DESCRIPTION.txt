[h1]Overlord[/h1]
Twitch viewers control your RimWorld colonists from a browser.

[b]Requires Harmony.[/b]

[b]You do not need Twitch, and you do not need to be streaming.[/b] Overlord runs two ways:

[list]
[*] [b]Local / friends mode[/b] — no Twitch, no relay, no stream. Leave the Relay URL blank in Mod Settings and your friends open your local address in a browser, type any name, and claim a colonist.
[*] [b]Twitch / stream mode[/b] — viewers log in with Twitch through a relay you host. There is no shared public server; each streamer deploys their own.
[/list]

[h2]Features[/h2]
[list]
[*] Assign colonists to Twitch viewers — or to friends, with no Twitch and no stream
[*] Browser control panel: needs, health, skills, map view, draft / move / work / gear
[*] Optional Twitch Toolkit Buy / Story bridge (Toolkit chat must be connected)
[*] Host tab for sessions, assignment, and permissions
[/list]

[h2]Install — playing with friends (no Twitch)[/h2]
[olist]
[*] Subscribe to [b]Harmony[/b], then [b]Overlord[/b]
[*] In Mod Settings → Overlord: leave [b]Relay Server URL blank[/b], note the local port (default 8421)
[*] Load a save, then send friends [b]http://<your-LAN-IP>:8421[/b]
[*] They type any name and claim a colonist — no Twitch login
[/olist]
Friends outside your network need a port-forward or a tunnel (Tailscale, cloudflared, ngrok). If only your own machine can connect, run RimWorld as administrator.

[h2]Install — streaming to Twitch viewers[/h2]
[olist]
[*] Subscribe to [b]Harmony[/b], then [b]Overlord[/b]
[*] Deploy your own relay (see the GitHub self-host guide)
[*] In Mod Settings → Overlord: set Relay URL + Host secret
[*] Send viewers your relay's public HTTPS URL (never the host secret)
[/olist]
